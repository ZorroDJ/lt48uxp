# Compact HC705 operation owner

Authored portable C host owner for six exact K1/J1A/KJ1 catalogue bindings.
The original pin procedures and verified idle FPGA are loaded only from a user's
SHA-bound GAD installation; none are embedded here.

Admission stage2 enables the two K1 manufacturer aliases after source-audit
qualification. Four J1A/KJ1 aliases remain held for protection applicability. The private
audit entry executes the whole owner over a simulated transport. An endpoint
pass is not factory-mode or silicon qualification. The library registers this authored source; admission remains per profile.
A resource entry alone does not admit all six candidate catalogue aliases.

See docs/audit-qualification/HC705_COMPACT_OPERATION_OWNER.md for memory,
operation, preservation, source-audit, deliberate Linux differences and the
two concrete factory-mode/protection gates. Do not raise admission.h from a
compiler match, a constructor count, or an ISA-effect model pass alone.

Program's instruction/address algorithm is source-derived. The authored owner
adds manufacturer-minimum controller dwell (K1 10ms, J1A/KJ1 4ms) and queues
fixed EPGM/CLR bytes in one transfer. The original Windows compiler, independent
rewrite and actual C authoring helper agree for these three derived waveforms.
Do not reuse the earlier model's acceptance of any pulse as timing evidence.

For K1, the unchanged stock factory Read is qualified by original interpreter,
USB09 reader and native capture/transport equivalence across4096 cases. The
original procedure is the oracle; a full model of undocumented on-chip test
logic is not required to reproduce it. Physical bus interpretation remains
hardware-pending. This does not waive the authored NUM gates for NMOS68705.

K1 source reuse also accepts the separately recognized AEC 7.60 and AEC 14.30
catalogues with their exact GAD file hashes and source-relative D/M labels.
The six-version comparison establishes identical device geometry, parameters,
pins and operation payloads. Execution semantics remain the qualified portable
C engine audited against Dataman 13.10; this is not a claim that every old
Windows host interpreter was executed. J1A/KJ1 remain held in all sources.
8.32, 11.60 and 14.40 were compared for evidence only and are not enabled.
