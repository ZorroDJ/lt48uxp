# AMD/TI bipolar PROM17 source profiles

Exact source/name/definition/family/pinmap/geometry bindings extend the existing
portable C compact PROM owner and normal GTK route. Source assets remain BYO.
Read, Blank Check, Program, Over-program, Verify and Compare are applicable;
these OTP parts have no erase operation. Source blank is0, with0-to1 programming.
The original initialization, bit-pulse procedure, voltages and pin maps are
retained. Audit receipts and hardware limitations are recorded in
`docs/audit-qualification/PROM_17_AUDIT.md` and `docs/data/prom17_stage*.json`.
