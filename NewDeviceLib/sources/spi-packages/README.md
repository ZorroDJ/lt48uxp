# SPI package extensions

Authored descriptor and exact-name/identity bindings for the existing portable C AddTab SPI owner. Original compact procedures, MCU applets and fitted FPGA configurations are loaded from the tester’s own Dataman 13.10 installation; none are embedded here.

The admission list is separate from candidate descriptors. Current staged cohort: **222 entries**. See `docs/audit-qualification/SPI_PACKAGES_222_AUDIT.md` and its qualification receipt. Original package-specific programming adapters are required; BGA/SO labels do not promise straight adapters. Hardware/analogue qualification remains pending.
