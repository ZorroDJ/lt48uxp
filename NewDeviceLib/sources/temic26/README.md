# TEMIC parallel OTP 8051 extension

Authored exact name/definition/family/pin/geometry bindings for 26 Dataman 13.10
entries. The existing portable C MCU51 owner executes BYO compact procedures
and FPGA data; no vendor resource bytes are included here. Secure maps the three
normal operator protection levels to cumulative individual lock flags consumed
by the original W5b procedure. Encryption is optional, after code verification.
No electrical erase is supplied. Physical qualification remains separate.
