# Tester report

Include:

- Distribution build: 0.1.0-test.20261123.1.
- Linux distribution/version and CPU architecture.
- Programmer model and selected database version.
- Exact selected device entry, physical marking, package and adapter wiring.
- Operation, expected outcome, actual outcome and steps needed to repeat it.
- Exported operation report where available, or exact error text.
- Programmer LED state after failure and whether reconnecting was necessary.

Distinguish a successful operation from independently checked contents. For a
read test, record whether the result was repeatable and compared with a known
image. For program/erase testing, use parts whose contents may be altered.
A successful test applies to the named sample and operations; it does not by
itself qualify every entry that shares an engine.

For a crash, run `./start-lt48uxp` from a terminal and retain its output. Report
adapter/contact changes too. Attach only the reports and images you intend to
share; proprietary memory contents are not required for an initial issue.
